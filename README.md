# Kindle Clone UI for KOReader (for personal use)

Makes KOReader look and feel like a Kindle. 

It's not a 1:1 replica, just as close as I could make it. For personal use to share with friends/family, cuz we love Kindle sooo much. LMK if you encounter issues.

- **Needs:** KOReader v2026.07 or later. And a bit of initial loading time if you have a large library.
- **Install:** copy the whole `kindle-clone-ui.koplugin` folder into `koreader/plugins/`


**First launch:** it asks two setup questions, then reads your book details (let the progress bar finish, it might take a while. **This is to help it later be fast at switching pages/folders.** If you have a big book library, just let it run for 5-15 minutes, or longer sorry, but it will only do this once on initial setup, any new books added after initial setup will automatically be scanned later too), and then it restarts KOReader once setup is finished.

---

**The Kindle UI menu works with these plugins (all optional):**

- **Auto warmth** schedule (sunrise/sunset) - comes with KOReader.
- **[LocalSend](https://github.com/kaikozlov/localsend.koplugin)** - installed separately.
- **[Airplane mode](https://github.com/kodermike/airplanemode.koplugin)** - installed separately.


**You can also access the default KOReader settings menu by clicking the cogwheel "All Settings".** 
For example, to enable or disable plugins, go into `All Settings > Tools > More tools > Plugin management`.
